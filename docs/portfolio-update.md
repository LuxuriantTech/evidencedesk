## Carte projet courte — anglais

### EvidenceDesk

Evidence-grounded document review for synthetic supplier operations. The application combines a
React/TypeScript interface, a FastAPI REST API, PostgreSQL/pgvector and Redis/ARQ. It supports
asynchronous ingestion, field-level evidence, explicit abstention, PII redaction and correlated
audit logs. Its locally locked holdout evaluations retain honest FAIL results and document both
metric and sealing limitations.

## Carte projet courte — français

### EvidenceDesk

Assistant de revue documentaire sourcée pour des dossiers fournisseurs synthétiques. L'application
associe React/TypeScript, une API FastAPI, PostgreSQL/pgvector et Redis/ARQ. Elle couvre l'ingestion
asynchrone, les preuves par champ, l'abstention explicite, le masquage PII et l'audit corrélé. Les
résultats holdout négatifs sont conservés avec leurs locks locaux et les limites de métrique et de
scellement.
